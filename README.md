# HKSI LE 試卷一｜題庫練習與模擬考

一個面向 HKSI LE Paper 1 備考的非官方靜態學習平台，包含題庫練習、錯題整理與限時模擬考。

## 線上使用

GitHub Pages：<https://dylan426-hub.github.io/hksi-le1-study-platform/>

網站需要口令才能解鎖學習內容。口令請向站點維護者索取。

## 發布結構

- `index.html`：站點入口
- `css/app.css`：介面樣式
- `js/app.js`：互動與本地學習進度
- `data/vault.js`：加密後的學習資料包
- `.nojekyll`：讓 GitHub Pages 直接發布靜態檔案

學習進度僅保存在使用者自己的瀏覽器 `localStorage`，站點不設後端，也不會上傳個人資料。
