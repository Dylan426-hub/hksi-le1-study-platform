# HKSI LE 試卷一｜題庫練習與模擬考

一個面向 HKSI LE Paper 1 備考的非官方靜態學習平台，包含題庫練習、錯題整理、可暫停模擬考、個人筆記與間隔復習速記卡。

## 線上使用

GitHub Pages：<https://dylan426-hub.github.io/hksi-le1-study-platform/>

網站需要口令才能解鎖學習內容。口令請向站點維護者索取。

## 發布結構

- `index.html`：站點入口
- `css/app.css`：介面樣式
- `js/app.js`：互動與本地學習進度
- `css/study.css`、`js/study.js`：個人筆記、錯因與速記復習
- `data/vault.js`：加密後的學習資料包
- `data/release.json`：本次修訂數量、題目版本與官方來源索引（不含題目正文）
- `tests/`：以虛構資料執行的本機回歸測試
- `.nojekyll`：讓 GitHub Pages 直接發布靜態檔案

學習進度僅保存在使用者自己的瀏覽器 `localStorage`，站點不設後端，也不會上傳個人資料。

## 2026-09-14 更新

- 根據公開 SFC 官方資料新增 5 道原創替代題，涉及 CPT 年度時數、超額時數不可結轉、AML 保存期、客戶協議與訂單保存期、投資者賠償上限。每题附規則核查日期、來源及條文定位。
- 原 793 道题目及歷史答案保留；其中 5 道舊版本停用，另 21 道有過時／存疑標記或重複選項的題目暫時隔離。加入 5 道新版後，當前可練習 772 道。
- 首頁可直接練習本次更新題；更新題使用新 ID，不會沿用舊題的正誤紀錄。隔離題不計入當前掌握率，舊紀錄仍保存在本機資料及備份內。
- 第 3、4、6 章新增補充要點，共 8 張速記卡。卡片按「再練／不熟／熟悉」安排下次復習；卡片評分與題目作答統計分開。
- 答題解析可以記錄個人筆記及錯因；「我的筆記」支援搜尋、直接編輯、匯出與合併匯入。筆記只存本瀏覽器，備份不含網站口令。
- 練習回看不重複計分；離開未完成的練習會保存進度。模考可手動暫停，切到背景或離開頁面時也會暫停；交卷只把已作答題目寫入刷題／錯題統計。模考總分仍按整份試卷計算，未答題會在成績中另外列出。
- 開始新一輪時會封存未完成的舊輪次。包含停用題或缺少必要作答資料的舊輪次不能繼續判分，可匯出並封存後重開；不會猜測或批量重判舊答案。

本次只完成上述 5 道題的公開規則核查，**不是整套題庫已更新，也不是 HKSI 官方試題**。尚未取得完整的現行官方溫習手冊，與正式考試範圍及手冊頁碼的逐題對照仍待核；其餘舊題會顯示待逐題核查。

## 本機檢查

在專案根目錄，以 Node.js 執行：

```sh
node --check js/app.js
node --check js/study.js
node tests/app.test.cjs
node tests/study.test.cjs
```

測試不解密題庫、不需要網站口令，也不讀取真實瀏覽器學習紀錄。靜態服務預覽與 GitHub Pages 發布無需安裝依賴。

## 資料與存取限制

網站口令用於在瀏覽器內解密學習資料，不是使用者帳戶或伺服器端權限控制。請勿在筆記輸入敏感資料。清除網站資料、使用私密瀏覽或更換瀏覽器，可能失去本機進度；請自行匯出備份。筆記與速記備份可在頁面匯入；完整作答歷史備份目前僅供留存或修復，沒有自助匯入功能。
