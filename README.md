# HKSI LE 試卷一｜題庫練習與模擬考

一個面向 HKSI LE Paper 1 備考的非官方靜態學習平台，包含題庫練習、錯題整理、可暫停模擬考、個人筆記與間隔復習速記卡。

## 線上使用

GitHub Pages：<https://dylan426-hub.github.io/hksi-le1-study-platform/>

網站需要口令才能解鎖學習內容。口令請向站點維護者索取。

## iPhone 主屏幕 App

這是可安裝的網頁 App（PWA），不是 App Store 或 TestFlight 套件。

1. 在 iPhone **Safari** 開啟上面的網址。
2. 點「分享」（部分版面先點「⋯」），選「加入主畫面／添加到主屏幕」。如出現「作為網頁 App 開啟」，保持開啟，再點新增。
3. 從主屏幕的 **HKSI P1** 圖示開啟，輸入原有口令。首次保持連線，在「iPhone 安裝、離線與備份」確認 **離線資料已備妥**。

[Apple 的主屏幕安裝說明](https://support.apple.com/zh-hk/guide/iphone/iphea86e5236/ios)。沒有加入主屏幕時，原網站仍可直接使用。

- 可離線重新開啟、輸入口令、作答、記筆記及復習速記卡；SFC/HKSI 外部來源連結仍需網路。
- 觸控按鈕至少 44px；可在安裝設定選擇 100%、125%、150%、200% 閱讀字體。不禁止瀏覽器縮放。
- 更新不會自動重新載入正在作答的頁面。檢查發現新版後，按「保存進度並更新」才會套用；模考先暫停。若進度或筆記未保存成功，會阻止重新載入。
- 系統清理儲存空間、清除網站資料或刪除 App，仍可能丟失記錄／離線檔案，請定期備份。[WebKit 儲存政策](https://webkit.org/blog/14403/updates-to-storage-policy/)

### 遷移記錄

電腦、Safari 與主屏幕 App 的本機資料不保證共用，也不會自動雲端同步。在原來的版本匯出完整 JSON 備份，透過「檔案」或 AirDrop 傳到 iPhone，再於新安裝輸入口令後選「遷入完整備份」。

只接受沒有學習資料的空白安裝；不會合併或覆蓋已有作答。格式錯誤、未知題目版本或超出上限會整檔拒絕。未完成模考以暫停狀態遷入，不補扣傳送期間的時間，也不自動判分。完整備份上限 8 MB；歷史模考及封存各最多 1,000 筆；單題筆記最多 20,000 字。已有筆記的安裝可繼續使用原本的筆記合併匯入（1 MB 上限）。

遷移檔案不含網站口令，但含個人學習記錄。只匯入自己的備份，並保留原檔。口令仍可交由使用者自己的 Safari 密碼管理功能填寫；本 App 不把口令新增到永久本機設定。

## 發布結構

- `index.html`：站點入口
- `css/app.css`：介面樣式
- `js/app.js`：互動與本地學習進度
- `css/study.css`、`js/study.js`：個人筆記、錯因與速記復習
- `data/vault.js`：加密後的學習資料包
- `data/release.json`：本次修訂數量、題目版本與官方來源索引（不含題目正文）
- `manifest.webmanifest`、`icons/`：主屏幕名稱、啟動範圍與圖示
- `sw.js`：按站點路徑隔離的版本化離線快取（僅程式、圖示與加密題庫）
- `js/install.js`、`css/mobile.css`：安裝引導、字體大小、離線檢查及手機版面
- `js/migration.js`：完整備份的純校驗模組，不讀寫口令或網路
- `tests/`：以虛構資料執行的本機回歸測試
- `.nojekyll`：讓 GitHub Pages 直接發布靜態檔案

學習進度僅保存在使用者自己的瀏覽器 `localStorage`，站點不設後端，也不會上傳個人資料。

## 2026-09-14 更新

- 根據公開 SFC 官方資料新增 5 道原創替代題，涉及 CPT 年度時數、超額時數不可結轉、AML 保存期、客戶協議與訂單保存期、投資者賠償上限。每题附規則核查日期、來源及條文定位。
- 原 793 道题目及歷史答案保留；其中 5 道舊版本停用，另 21 道有過時／存疑標記或重複選項的題目暫時隔離。加入 5 道新版後，當前可練習 772 道。
- 首頁可直接練習本次更新題；更新題使用新 ID，不會沿用舊題的正誤紀錄。隔離題不計入當前掌握率，舊紀錄仍保存在本機資料及備份內。
- 第 3、4、6 章新增補充要點，共 8 張速記卡。卡片按「再練／不熟／熟悉」安排下次復習；卡片評分與題目作答統計分開。
- 答題解析可以記錄個人筆記及錯因；「我的筆記」支援搜尋、直接編輯、匯出與合併匯入。筆記只存本瀏覽器，備份不含網站口令。
- 練習回看不重複計分；離開未完成的練習會保存進度。模考可手動暫停，切到背景或離開頁面時也會暫停；交卷只把已作答題目寫入刷題／錯題統計。模考總分仍按整份試卷計算，未答題會在成績中另外列出。
- 開始新一輪時會封存未完成的舊輪次。包含停用題或缺少必要作答資料的舊輪次不能繼續判分，可匯出並封存後重開；不會猜測或批量重判舊答案。

本次只完成上述 5 道題的公開規則核查，**不是整套題庫已更新，也不是 HKSI 官方試題**。尚未取得完整的現行官方溫習手冊，與正式考試範圍及手冊頁碼的逐題對照仍待核；其餘舊題會顯示待逐題核查。

## 本機檢查

在專案根目錄，以 Node.js 執行：

```sh
node --check js/app.js
node --check js/study.js
node tests/app.test.cjs
node tests/study.test.cjs
node tests/install.test.cjs
node tests/sw.test.cjs
node tests/migration.test.cjs
```

測試不解密題庫、不需要網站口令，也不讀取真實瀏覽器學習紀錄。靜態服務預覽與 GitHub Pages 發布無需安裝依賴。

圖示 PNG 已提交，正常使用無需生成工具。如需改圖示，可在有 `sharp` 的 Node.js 環境執行 `node scripts/generate-icons.cjs`。

### 後續離線版本發布

修改程式／題庫時，必須同步更新 `sw.js` 的 `VERSION`、有變動資產的版本網址，以及 `index.html` / `404.html` 的對應引用。舊頁面使用所屬版本的完整快取，新版先完整下載才可啟用；不要只改資產而重用已發布的版本號。不要在 `install` 中自動 `skipWaiting` 或強制重新載入使用者頁面。

離線狀態只有在所有核心檔案已驗證存在後才顯示備妥。快取若不完整，會提供獨立恢復頁；使用者連線後點恢復，只註銷本網站的精確 Service Worker 範圍並重新開啟，不清除學習紀錄或其他站點快取。

## 資料與存取限制

網站口令用於在瀏覽器內解密學習資料，不是使用者帳戶或伺服器端權限控制。請勿在筆記輸入敏感資料。清除網站資料、使用私密瀏覽或更換瀏覽器，可能失去本機進度；請自行匯出備份。筆記與速記備份可合併匯入；完整作答歷史備份只可遷入沒有學習資料的新安裝。
